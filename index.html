공동 작업 전체 결과: 72개 항목 검토 · 44개 변경 · 28개 유지.

교육 팀 프로젝트 · 2023.03 ~ 2023.05

AWS 웹 애플리케이션 보안 강화

K-Shield Junior 10기 팀 프로젝트에서 AWS 설정에 참여했습니다. 프로젝트는 VPC·서브넷·EC2·ALB·WAF·S3를 활용한 웹 환경 구성과 보안 실습을 다뤘습니다.

팀 결과: 접근통제와 XSS·SQL Injection 방어 로그 확인.
